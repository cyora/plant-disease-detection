# Plant Leaf Disease Detection

Web application that detects plant leaf diseases from a photo using deep learning (transfer learning on the PlantVillage dataset).

## Stack
- Model: TensorFlow/Keras (MobileNetV2, EfficientNet), trained on Kaggle Notebooks
- ML API: FastAPI
- Backend: Spring Boot
- Frontend: Angular

## Dataset
PlantVillage (Hughes & Salathé, 2015): 54,303 images, 38 classes.
